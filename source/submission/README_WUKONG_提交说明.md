## 游戏实现与验证
- 人物：按待机姿态下的真实可见蒙皮顶点校准尺度，保留网格测量、不计骨架节点；动画缺失不再任取 Death；修复拖尾短轨迹越界。
- 场景：水帘细流、立体火墙、柔边粒子、倒角石道与弯曲草叶、贴地火山裂隙、实体大理石铺装；保留既有 CC0/Aholo 资产，无新增外部素材。
- 对打：敌人前摇锁方向、攻击后有恢复窗口，狼/骸骨/史莱姆分别读招；Boss 专属模式与方向预警，悟空命中窗口推迟至挥击中段；近 Boss 自动拉远。
- 声音：单路语音，字幕时长跟随音频；按实际句长 duck BGM/环境；修复环境循环首次不启动、同一帧重叠触发报错；探索/交战/狂暴分层音量，取消整体升调。
- 性能：主 JS 约 1.07 MB（gzip 约 275 KB），旧版 3.76 MB（gzip 1.23 MB）；复用标题场景，道具分帧加载且章内共享资源；补齐粒子/骨骼/战斗特效释放。
- 验证：`npm run build`；`docs/qa/ 下的验证脚本` 与原始 JSON；`docs/MEMORY_QA.md`、`docs/AUDIO_QA.md`。
- 尚未验收：跨设备稳定 60fps、全部冷启动任务 <200ms、真人表演配音、独立玩家正常操作完整打通、统一美术语言及获奖竞争力。开发测试注入伤害仅验证状态机，不冒充玩家通关。
- 报告共 7 页；源码与报告生成器可编辑。现有提交包的旧快照保留为历史，当前源码以工程 `src/` 为准。

普通入口键鼠自动化已打通三回，触发「新的妖王」结局。四段轻棍使用横扫、反撩、探棍和回身扫轨迹。启动仍有超过 200ms 的长任务，公网样本最高 1056ms。

擎天重劈使用举棍、下砸、压身收势；落棍统一触发伤害判定和音效，接地时生成震波。

三回当前各有主题、环境、阶段层与入场/转阶段提示音。新增声层由项目内脚本离线生成，沿用既有环境底声。

- 项目源代码：https://github.com/MinusPlus2025/wukong-game/tree/main/source

三回使用分章天空与统一的材质光照。南天门以盘云烛龙守门，半血时龙身离开云座；龙首领飞一圈，背脊和尾尖按弧长跟随，再回身锁定悟空吐息。云座留在起飞处。飞行体节复用原雕刻颈段的 UV、法线与材质，回头时颈根随头部转动。南天门设石质星盘、铜纹浑仪与透空石栏。地面预警与伤害扇区从龙口的地面投影起算。

南天门石台采用分层石沿与铜收边。半血腾空时门下铜镜转动、云海向外分流、星盘嵌纹显光，回身瞄准时光效回落。头颈从同一批原雕刻三角形裁切，烘焙时逐个核对接缝位置、UV 和法线。

龙息前摇保留完整扇形边线，一道亮纹沿攻击方向走到外缘，随后龙口喷出分束火流。完美闪身的龙息范围与命中判定共用同一个函数。
