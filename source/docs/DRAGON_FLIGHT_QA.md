# 凌霄天龙实战复核

从游戏原入口点击披挂上阵，通过两回六根抉择进入南天门。用棍击打到半血后停手，观察空云座、龙首绕行、背尾追随、回首和首个吐息。普通玩家录像使用游戏自带镜头；对照录像仅在绘制时使用固定的世界坐标 (8, 5.8, 15)，看向 (0, 2, 2.6)，垂直视场角 46°。两次战斗独立进行，没有跳关或写入血量。

1920 × 1080 的一次公网普通镜头录制中，从半血前 0.3 秒至首个吐息后 0.5 秒，浏览器动画帧间隔共 1229 个，P95 为 9.2 ms，最大 9.4 ms。实际渲染材质检查：一阶段烛龙、二阶段龙首与飞行脊背引用同一材质实例及颜色、粗糙度和金属度贴图。吐息瞬间龙口水平轴与伤害轴差 0°；实际绘制的扇焰与预警中心线相差小于 0.001°，起点的水平距离小于 0.001 世界单位，扇区半径为 10。记录限于本机本次过渡窗口。

可用浏览器 Performance 面板观察 wukong-dragon-rise 和 wukong-dragon-breath。伤害方向为锁定的 attackYaw；龙口坐标来自原雕刻的嘴尖顶点，地面警戒起点取其水平投影。

颈部烘焙检查：运行 python3 scripts/bake_dragon_flight.py，截面两侧 245 个独立位置／法线／UV 组合逐一相等。腾空时检查腰腹侧摆传向尾尖、门下悬镜转动、石台铜纹逐渐显光，回身时显光回落。
