# 《大圣破阵录》资深设计/开发审计

版本：三回可玩版（v2 战斗系统已并入主链接）  
审计视角：动作游戏设计 + 3D 生产管线 + 评审标准  
结论：**“有技术亮点的原型”，还不是“完成度合格的动作游戏”**。

## 2. 玩家幻想与核心循环

**一句话**：玩家不是“看悟空模型”，而是“用一根棍子读招、破防、处决，决定自己变成什么样的妖”。

核心循环（目标 30 秒）：

1. 看红光/前摇 → 选择弹反或闪身
2. 弹反成功 → 躯干条上涨 → 破防
3. 破防 → F 处决 → 回棍势 / 回血
4. 清场 → 收灵蕴/听碎片 → Boss 阶段变化
5. 结算评价 → 再打 S / 全灵蕴 / NG+

现在 1–3 已经成立；4 是刚加的；5 刚加但缺反馈闭环。

---

## 3. 三回的身份必须分开

现在三回是“换颜色 + 换 Boss 模型”，机制几乎一样，这是“玩一次就不想玩第二次”的根因。

| 回目 | 身份 | 独有机制 | 玩家问题 |
|---|---|---|---|
| 花果山 | 教学/识破 | 弹反教学、石灯/石狮、灵蕴 | “我能不能不挨打？” |
| 火焰山 | 资源/环境 | 火墙、扇形灭火、持续灼烧 | “先灭火，还是先杀妖？” |
| 南天门 | 处决/高危 | 天雷预警、云台位移、Boss 多阶段 | “我敢不敢在雷里处决？” |

**P0**：每回至少一个“只有这回才有”的机制；否则三回就是同一关打三遍。

## 4. 战斗设计差距

### 4.1 敌人
- `yaoguai-guard.glb` **无骨骼/无动画**，移动只能滑/倾，不能真跑。
- 三个 Boss 的 AI 共用“追→前摇→砸地/冲锋/震波”，只靠数值区分。
- 小怪攻击模式单一，没有远近/包夹/自爆/远程。

### 4.2 玩家
- 4 段轻棍 + 重劈 + E 横扫已成立；但**缺少攻击取消规则**：哪些招可被闪避取消、哪些是承诺。
- 弹反窗口 0.34s、冷却 0.7s；Boss 攻击前摇 0.5–1.15s；需要按 Boss 调，而不是全局。
- 处决只对“破防”生效，缺少**处决动画/镜头**，现在只是伤害数字。

### 4.3 失败与重试
- 已加 **Boss 检查点**：清完小妖后死亡不再重打整章，直接在 Boss 前复活。
- 还缺：Boss 招式图鉴/死亡回放/失败原因提示。

## 5. 探索与重玩

已加：
- 每回 3 个隐藏灵蕴（9 个），碎片叙事 + 永久强化
- 章节评价 S/A/B（时间、受伤、灵蕴）
- NG+（敌人 +35% 血、+16% 伤害）

还缺：
- 灵蕴没有“环境线索”（现在纯靠碰），应加**风声/微光/石灯指向**。
- 评价只显示在结算，缺**章节选择页的历史最佳**。
- NG+ 没有新规则，只是数值；应加“敌人多一招/灵蕴位置变”。

## 6. 生产管线差距

| 环节 | 现状 | 问题 |
|---|---|---|
| 角色 | Lux3D 生成 + rig/retarget | 小妖静态；武器 socket 靠手骨世界坐标 |
| 场景 | 3DGS + Aholo 道具 | 花果山最完整；火焰山/南天门仍偏空 |
| 动画 | Wukong 6 clip、Bullking 4 clip | 没有上下半身分层、没有 IK、没有处决演出 |
| 音频 | ChatTTS + Kokoro/CC0 + SoX | TTS 不是演员；BGM 是库存曲 |
| UI | EVA 技术 HUD | 信息密度高，首次引导弱 |
| 性能 | 3DGS + 压缩模型 | 首屏/章节加载仍慢，低端机风险 |

## 7. 按优先级整改

### P0（不做就不算完成）
1. **小妖 rig + 跑步/攻击动画**（Aholo 动画任务；失败则换已带动画模型）
2. **每回独有机制**（火墙/天雷/云台，至少一个）
3. **Boss 检查点 + 失败原因**（检查点已做，补提示）
4. **首 60 秒教学**：第一只小妖只做一次可弹反攻击，HUD 提示 F
5. **报告/源码/链接三者一致**（三回、当前功能、真实 taskId）

### P1（决定“想不想再打”）
6. 章节历史最佳评价/灵蕴收集
7. NG+ 新规则，不只数值
8. 处决镜头/语音/动画
9. 三回各自 Boss 的 3 套招式与阶段演出
10. 音频：真人配音或参考声，BGM 换原创

### P2（传播）
11. 15 秒“弹反→破防→处决”钩子
12. 章节选择页的探索进度/秘密提示
13. 手柄/键位/无障碍

## 8. 验收指标

- 首次进入 60 秒内，玩家至少完成一次 **弹反 + 破防 + 处决**
- 单回 4–6 分钟，三回 12–15 分钟
- 死亡后 5 秒内回到 Boss 前，不重打小怪
- 每回至少 2 个“只有这回才有”的机制/敌人
- 三回各有一个 S 评价可挑战
- 报告、源码、Demo 三处功能/数字一致
