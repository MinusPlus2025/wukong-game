# 大圣破阵录 / WUKONG: CELESTIAL SHATTER — 提交说明

## 一句话
3D AI 花果山动作游戏：三回、三 Boss、四神通；不是模型展示，是一场能打通、能打爽的 3D 动作垂直切片。

## 本次重做
- **音效**：金属棍风、重击低频、地面裂开噪声、铜锣/鼓、Boss 低频咆哮、芭蕉扇风墙。
- **配乐**：原创 64 秒合成战斗曲（太鼓/低音鼓/金属锣/五声音阶拨弦）；三回环境音。
- **配音**：14 句标准普通话男声（Edge Yunjian），逐句对齐字幕，无方言/无额外语气字；统一约 -16 LUFS，短混响。
  俺老孙来也 / 吃俺一棒 / 碎 / 闪 / 定 / 风来 / 法天象地 / 妖怪哪里逃 / 俺老孙去也 / 选根 / 两结局 / 妖王受死 / 残血。
- **修复**：开局“敌人异步生成期间空数组触发通关”的竞态；音频预加载阻塞开局；Boss 拉近、镜头收紧、岩环/石灯/红幡/月亮补场景。
- **录制**：15 秒实机，canvas + Tone.js 音频流一起录进 WebM，转 H.264 + AAC。
